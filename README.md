# Mesto

Проектная работа **Mesto** с подключением к серверу.  
Приложение позволяет:

- загружать информацию о пользователе с сервера;
- загружать карточки с сервера;
- редактировать профиль;
- обновлять аватар;
- добавлять новые карточки;
- удалять свои карточки;
- ставить и снимать лайки;
- открывать изображение в полном размере;
- просматривать информацию о карточке.

## Ссылка на опубликованный проект

https://annett-a.github.io/mesto-production/

## Запуск проекта

Установка зависимостей:

```bash
npm install
```

Запуск локального сервера разработки:

```bash
npm run dev
```

Сборка проекта:

```bash
npm run build
```

Публикация проекта:

```bash
npm run deploy
```
